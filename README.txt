BẢN THIẾT KẾ HIỆN ĐẠI - TAND KHU VỰC 3 NGHỆ AN

Phong cách:
- Ngôn ngữ thị giác của website cơ quan Nhà nước: đỏ, trắng, vàng nhấn; bố cục chính thống.
- Hiện đại: typography sạch, card, khoảng trắng, micro-interaction, responsive.
- Không sử dụng Quốc huy thật trong bản mẫu để tránh tạo nhận diện giả; biểu tượng cân thay thế có thể đổi thành logo/nhận diện chính thức khi được phép.

Đưa lên GitHub Pages:
1. Vào https://github.com/
2. New repository -> Public.
3. Upload index.html, style.css, script.js.
4. Settings -> Pages -> Deploy from a branch -> main -> /root -> Save.
5. Địa chỉ sẽ dạng https://TEN-TAI-KHOAN.github.io/TEN-REPOSITORY/

Biểu mẫu:
- Tạo các thư mục forms/hinh-su, forms/dan-su, forms/hanh-chinh.
- Đặt PDF/Word vào đúng thư mục.
- Sửa đường dẫn trong script.js nếu tên file khác.
